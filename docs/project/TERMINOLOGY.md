# 术语表

## 1. 产品与阶段

| 标准术语 | 定义 | 禁止或注意 |
|---|---|---|
| Phase 1A 批次A | 当前唯一授权阶段：规格、流程、低保真原型、技术草案与证据 | 不得简称为“已开发版本” |
| Phase 1A 批次B | 后续候选批次 | 当前禁止启动 |
| Phase 1B | 后续正式推进阶段 | 当前禁止启动 |
| 低保真原型 / 非正式系统 | 可离线审查的信息结构与交互演示 | 不得称生产系统、测试环境或正式应用 |
| 内部证据门禁通过 | 文件和验证证据满足当前合同 | 可写 `PASS`，但必须同时写“待项目负责人验收” |

## 2. 用户与端

| 标准术语 | 定义 | 锁定规则 |
|---|---|---|
| 访客 | 未登录或未成为机构成员的公众用户 | 当前产品名称禁止使用“游客”替代 |
| 访客状态 | 用户尚未登录或未绑定机构身份的状态 | 技术枚举可用 `VISITOR` |
| 访客端 | 面向访客的微信小程序和用户网页能力 | 不包括机构管理网页端 |
| 访客首页 | 公众进入产品的首页 | 可承载网页端家校共育、联系或预约的合并入口，但验收点不能丢失 |
| 家长 | 经机构审核、与学生建立关系的监护侧用户 | 不等同于访客 |
| 教师 | 具有班级或教学工作范围的机构成员 | 数据范围必须受机构与班级限制 |
| 工作人员 | 具有内部指南、资源或业务职责的机构成员 | 权限按岗位授予 |
| 机构管理员 | 管理本机构配置、内容、账号与审核的成员 | 不拥有跨机构权限 |
| 校区负责人 | 管理授权校区范围的负责人 | 必须受 `campus_id` 限制 |
| 平台管理员 | 维护 SaaS 平台的角色 | 默认不得查看学生具体内容 |
| 微信小程序 | 现场、即时、轻量、拍照上传与快捷处理端 | 不机械复制网页 |
| 用户网页端 | 完整查看、历史、长内容和复杂编辑端 | 不承担机构后台管理 |
| 机构管理网页端 | 配置、权限、表格、统计、审核和批量管理端 | 访客不支持 |

## 3. 数据与架构

| 标准术语 | 定义 | 强制规则 |
|---|---|---|
| 租户 / `tenant_id` | 一个独立机构及其数据安全边界 | 机构业务表、查询、写入、缓存、任务、文件、审计、AI会话与成本均隔离 |
| 校区 / `campus_id` | 租户内的校区数据范围 | 校区业务必须携带并校验 |
| Membership | 用户与一个机构的成员关系 | 角色与数据范围从可信身份和成员关系解析 |
| 模拟数据 | 明显虚构、不可回溯真人、仅供原型的内容 | 必须标注；不得仿照真实未成年人资料 |
| 真实数据 | 可识别或可关联真实学生、家长、教师或工作人员的信息 | 当前批次禁止使用 |
| 生产密钥 | 可访问生产或外部服务的口令、令牌、证书或密钥 | 禁止读取、生成、写入、回显或提交 |

## 4. 关键业务术语

| 标准术语 | 定义 | 不得混淆 |
|---|---|---|
| 教师工作日报 | 任务、考勤、接送、学生记录和异常自动汇总后，由教师补充总结的工作记录 | 不等于学生托管日报，不应退化成重复手工表单 |
| 学生托管日报 | 面向单个学生托管情况的记录 | 不替代教师工作日报 |
| 家长与学生绑定 | 登录、手机号、邀请码与学生信息、机构审核、建立关系的流程 | 不得跳过机构审核 |
| 同芯AI学习助手 | 小学作业引导与错题巩固能力 | 不是开放聊天、代写、陪伴或诊断工具 |
| 第0—3层提示 | 从确认尝试到必要时完整讲解的递进提示 | 不得直接泄露答案 |
| 巩固层 | 生成1—3道同类题验证理解 | 不等同于新一轮开放聊天 |

## 5. 状态词

- 允许的阻塞文件无阻塞状态：`NO_BLOCKERS`。
- `PASS`：内部证据门禁通过、待项目负责人验收。
- “已验收”：仅项目负责人明确确认后使用。
- “已部署”“生产可用”“正式上线”：当前阶段禁止作为事实声明。
