## 2. 产品范围

- 访客端：品牌首页、机构介绍、文化与家校共育、活动、餐食、教师介绍、校区联系和公开内容；
- 家长端：模拟孩子状态、通知、安全接送、绑定流程和监督式学习入口；
- 教师端：任务、班级状态、异常、工作日报、资源和 AI 摘要；
- 机构管理网页：内容、教师、活动、餐食、指南、资源、文件、发布、日志、权限和统计的高保真审查界面；
- AI 学习助手：小学作业引导和错题巩固，不提供开放式聊天或代写。

三端共享统一业务规则的原型表达，但不机械复制布局。管理端只在网页呈现；小程序强调现场和快捷操作；用户网页强调历史、长内容和复杂编辑。

## 3. 流程范围

12 个 B 级流程全部保留 Batch A 的页面 ID、路由、状态、角色守卫和终态。至少验证：

1. 家长/教师监督下的学生绑定；
2. 教师任务开始、完成、日报编辑、提交和后续查看；
3. 学生先尝试、AI 第 0 至第 3 层提示、1 至 3 道巩固题、转教师摘要和关闭；
4. 表单输入、校验错误、加载、空状态、终态、弹窗、抽屉、标签页和筛选；
5. 非法跳步、越权、跨角色摘要和 AI 越级均被拒绝。
