# 三端功能矩阵

## 1. 读法

本表严格使用合同指定列。单元格写明该端的交互责任；`—` 表示该角色与端不支持。阶段标签只表达产品范围分类，不表示已正式开发：

合同指定列未单列“工作人员端”；V0.1内部员工能力在“教师小程序/教师网页”两列表示用户端承载位置，实际教师与工作人员权限仍分别遵循 `ROLE_MATRIX.md`，不会因此把班级或学生权限授予工作人员。

- `V0.1正式开发`：V0.1 的正式范围定义，本批次只产出规格和低保真原型；
- `后续关键流程原型`：本批次必须制作可操作概念原型，但不实现真实服务；
- `未来结构预留`：仅保留结构和边界，不制作业务功能。

## 4. 统一安全边界

所有机构业务在未来实现时受 `tenant_id` 限制，校区业务受 `campus_id` 限制。平台管理员默认无权查看学生具体内容。当前矩阵只定义产品行为，不授权真实数据、正式 AI、支付、外部 API、依赖安装、部署、推送或任何后续阶段。
