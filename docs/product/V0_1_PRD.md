# V0.1 专项 PRD

## 1. 版本定义

V0.1 定义三条正式产品线：访客产品线、内部员工产品线、轻量机构管理后台。本文是 Phase 1A 批次A的范围规格，不表示正式应用已经开发、部署或上线。

所有展示内容均使用标注为“模拟数据”的虚构占位内容。V0.1 不处理真实学生业务数据。

## 2. 目标与验证问题

V0.1 要验证：

1. 访客是否能从小程序或网页完整了解机构并找到联系/预约意向入口；
2. 员工是否能快速进入指南、教学资源、资源搜索和伙伴云快捷链接；
3. 机构管理员是否能在轻量后台维护上述内容、发布/下架/排序并查看基础操作日志；
4. 合并后的信息架构是否仍完整保留所有锁定内容和独立验收点；
5. 三端职责是否符合“小程序轻量、网页完整、后台治理”的分配。

## 3. 用户与前置条件

| 用户 | 前置条件 | 使用端 | 数据范围 |
|---|---|---|---|
| 访客 | 无登录要求 | 微信小程序、用户网页端 | 仅已发布公开内容 |
| 教师/工作人员 | 概念登录并具有效 Membership | 微信小程序、用户网页端 | 所属租户内被授权的内部内容 |
| 机构管理员 | 概念登录并具机构管理权限 | 机构管理网页端 | 所属租户及授权校区 |
| 校区负责人 | 概念登录并具校区管理权限 | 机构管理网页端 | 所属租户的授权 `campus_id` |

当前登录均为原型概念，不接入真实账号、短信或微信授权。

| `V01-PUB-04` | 家校共育 | 独立页面 | 并入访客首页或机构介绍 | 网页有独立区块/锚点和明确入口 |

### 4.1 访客主路径

```text
访客首页
→ 选择机构介绍/教师/活动/餐食/一日流程
→ 查看详情
→ 返回公开导航或进入联系/预约意向
→ 查看“已记录模拟意向，等待机构人工联系”的终态
```

不发送短信、不创建真实线索、不调用外部服务。

## 6. 轻量机构管理后台

| `REQ_ID` | 能力 | 主要操作 | 状态/审计 | 验收要点 |
|---|---|---|---|---|
| `V01-ADM-01` | 机构资料 | 编辑简介、服务、企业文化、校区环境、联系入口 | 草稿/发布/下架；留操作记录 | 企业文化与校区环境字段不可丢失 |
| `V01-ADM-02` | 首页内容 | 编辑区块、选择内容、预览 | 草稿/发布/下架 | 双端公开结果可追踪到发布版本 |
| `V01-ADM-03` | 教师公开介绍 | 新增、编辑、选择公开字段 | 草稿/发布/下架 | 与内部教师档案严格区分 |
| `V01-ADM-04` | 活动 | 新增、编辑、设置时间与媒体 | 草稿/发布/下架 | 已发布内容才对访客可见 |
| `V01-ADM-05` | 餐食与食谱 | 新增、编辑日期、餐次和菜品 | 草稿/发布/下架 | 不录入真实学生健康信息 |
| `V01-ADM-06` | 新人指南 | 新增、编辑、限定内部可见 | 草稿/发布/下架 | 访客不可访问 |
| `V01-ADM-07` | 教学资源 | 新增、编辑、分类、范围设置 | 草稿/发布/下架 | 员工只见授权范围 |
| `V01-ADM-08` | 伙伴云链接 | 新增、编辑、发布/下架、启用/停用、角色限制 | 发布状态与运行状态正交 | 只有PUBLISHED+ENABLED（active）可展示/进入；不存凭据、不调用 API |
| `V01-ADM-09` | 员工账号 | 查看模拟成员、分配概念角色 | 启用/停用 | 不实现真实账号和认证 |
| `V01-ADM-10` | 文件管理 | 查看、选择、替换模拟媒体 | 可用/已归档 | 文件受租户前缀和引用权限约束 |
| `V01-ADM-11` | 发布、下架和排序 | 发布/下架；列表内上移、下移或设序号 | 每次动作记录操作者、时间、对象与前后状态 | 排序是相关列表操作，不另建页面但有独立控制和验收 |
| `V01-ADM-12` | 基础操作日志 | 按对象、动作和时间筛选 | 只读 | 不允许普通内容编辑者篡改日志 |

### 6.1 内容发布主路径

```text
机构管理员模拟登录
→ 选择内容对象
→ 新建或编辑草稿
→ 预览并确认权限范围
→ 发布
→ 小程序与用户网页读取同一已发布版本
→ 后台日志记录动作
```

### 6.2 排序操作

排序并入教师、活动、餐食、指南、资源等管理列表。每个相关列表必须提供明确的上移、下移或序号操作，保存后显示新顺序并生成基础操作日志。合并不取消独立验收点 `V01-ADM-11`。

## 7. 信息架构合并追踪

| 原锁定内容 | 合并位置 | 保留的独立能力 | 验收 ID |
|---|---|---|---|
| 企业文化 | 小程序/网页机构介绍；后台机构资料 | 独立区块、锚点、字段、编辑与公开读取 | `V01-PUB-03`、`V01-ADM-01` |
| 用户网页家校共育 | 访客首页或机构介绍 | 独立区块、锚点、内容与进入路径 | `V01-PUB-04` |
| 用户网页校区联系 | 访客首页或机构介绍 | 校区信息、环境与联系方式独立区块 | `V01-PUB-10` |
| 用户网页预约 | 访客首页或机构介绍 | 最小意向表单、确认状态和隐私提示 | `V01-PUB-11` |
| 用户网页资源搜索 | 教学资源页面 | 搜索、筛选、无结果、清除条件 | `V01-STAFF-05` |
| 排序 | 后台相关内容列表 | 上移/下移或序号、保存结果与日志 | `V01-ADM-11` |

禁止用“已并入”替代上述内容、字段、流程或验收证据。

## 8. 权限与数据规则

- 公共读取仅返回 `已发布` 且标记为对外公开的内容；
- 内部员工内容要求有效 Membership 和明确的租户/校区/角色范围；
- 后台写操作要求机构管理员或授权校区负责人权限；
- 服务端未来从可信身份自动注入 `tenant_id` 和适用 `campus_id`，拒绝前端覆盖；
- 平台管理员默认不能进入机构学生内容；V0.1 也不提供此入口；
- 教师公开介绍只含对外批准字段，内部教师档案不得经公开接口返回。

## 9. 内容与状态

内容对象字段见 `CONTENT_SCHEMA.md`。公开与内部内容均使用 `草稿 → 已发布 → 已下架` 状态模型；非法转换、无权限、空结果和读取错误的处理见 `STATE_MODEL.md`。

## 10. V0.1 明确非范围

- 家长与学生绑定、家长首页、学生每日托管记录、请假和安全接送的正式实现；
- 教师任务、班级学生情况、教师工作日报的正式实现；
- 同芯AI学习助手的正式模型、真实学生会话或真实评测；
- 财务与费用、教师绩效、招生、证照、物资、多校区经营、SaaS 套餐、微信支付、AI阅读与学习计划、平台运营的正式功能；
- 正式微信小程序、Next.js 用户端、机构管理后台、NestJS API、数据库迁移和应用脚手架；
- 真实登录、短信、微信授权、伙伴云 API、支付、生产数据库、生产密钥、云部署或 Git 推送；
- 真实学生、家长、教师、工作人员数据。

B级关键流程仅在本批次制作可操作的低保真概念原型，不属于 V0.1 正式开发。

## 11. 异常与降级

| 场景 | 用户反馈 | 安全动作 |
|---|---|---|
| 无公开内容 | 显示“暂无已发布内容”与返回入口 | 不回退展示草稿 |
| 无内部权限 | 显示权限不足和联系机构管理员 | 不暴露对象是否存在 |
| 搜索无结果 | 显示条件摘要、清除条件与返回分类 | 不扩大到其他租户 |
| 内容加载失败 | 保留导航，显示重试与返回 | 不伪造缓存结果 |
| 快捷链接不可用 | 显示不可用和返回工作台 | 不请求或保存外部凭据 |
| 发布冲突 | 显示版本已变化，要求刷新后复核 | 不覆盖他人更新 |

## 12. V0.1 完成判定

本规格层面的完成需要：范围与非范围齐全；三端页面可追踪；六项合并映射均有独立验收 ID；公开、内部和后台三条路径闭合；内容/状态/权限一致；所有示例仅为模拟数据；不存在真实集成或生产声明。详细证据见 `ACCEPTANCE_CRITERIA.md`。
