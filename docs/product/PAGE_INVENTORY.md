# 页面清单

## 1. 计数与字段规则

本清单固定为 `A=47`、`B=12`、`C=10`，合计69项。A级由小程序20项、用户网页13项、机构管理网页14项组成。每项均给出稳定页面ID、路由、端、角色、阶段、入口、主要区域、主要操作、可操作状态、空状态、错误状态、权限要求、数据对象和验收点。

路由仅用于离线低保真原型，不是生产URL。页面中的个人或机构样例必须标注“模拟数据”。

### 3.1 三条完整业务闭环

1. `B-FLOW-01 → B-FLOW-02`：申请严格按微信登录概念、手机号、邀请码+学生姓名+班级、机构审核、建立关系；拒绝可修改重提，通过进入家长首页，解除回到未绑定。

3. `B-FLOW-12 → B-FLOW-10 → B-FLOW-11 → 教师工作台`：家长/机构开关允许后开启，学生先尝试并完成分层提示与巩固，摘要只回流教师；安全失败转教师或关闭。
