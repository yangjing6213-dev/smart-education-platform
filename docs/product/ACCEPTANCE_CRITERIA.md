# Phase 1A 批次A验收标准与追踪矩阵

## 1. 结论语义

- `PASS` 只表示内部证据门禁通过、等待项目负责人验收；不表示项目负责人已经验收、生产可用或正式上线。
- 本文定义标准和证据位置，不把计划、文件存在或作者自述当作实际验证结果。
- 实际命令、退出码、文件哈希、截图或静态回退证据、Git提交和限制必须写入阶段线程回执，A6再固化到最终评审报告。
- 任一关键标准失败且不能在当前任务白名单内修复时，必须记录 `BLOCKED` 并停止；不得进入后续阶段。

### 5.1 B级逐项门禁

每个 `B-FLOW-01` 至 `B-FLOW-12` 必须同时满足：

1. 至少一个可点击动作改变界面可观察状态；
