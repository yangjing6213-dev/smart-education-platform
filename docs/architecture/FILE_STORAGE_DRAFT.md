# 文件存储草案

## 1. 边界

未来候选文件服务为腾讯云 COS；本批次不创建桶、账号、策略、上传代码、真实文件或签名链接。原型只使用自制占位图、CSS 图标和简单 SVG。

## 2. 文件生命周期

```text
业务对象请求上传意图
→ 服务端校验身份、tenant/campus范围、用途、类型与大小策略
→ 服务端生成不透明MediaAsset与COS key
→ 签发限定对象/动作/大小/类型的短时上传授权
→ 上传完成回调/确认
→ 服务端检测MIME、大小、SHA-256与安全状态
→ AVAILABLE
→ 被内容版本引用为REFERENCED
→ 解除引用后ARCHIVED
→ 按批准策略删除或保留最小审计
```

任何检测失败、范围冲突或上传未完成都不能进入可引用状态。当前只描述流程，不运行真实上传或恶意文件扫描。

授权时限和上传上限沿用已批准的 `FILE_STORAGE_BASELINE.md`：上传目标 10 分钟过期，下载目标 5 分钟过期；单张图片最多 10 MiB，单份文档最多 25 MiB。R4 不改变这些基线值。

## 3. 对象键与隔离

概念键：`tenant/{tenantId}/campus/{campusId-or-tenant}/{purpose}/{fileId}/{safeName}`。服务端生成租户、校区、用途和对象 ID 片段；`safeName` 仅采用标准化后的非敏感显示名，不决定目录或授权。租户级文件使用明确的 `tenant` 校区段，校区级文件使用可信 `campus_id`；不允许客户端枚举或直接指定 COS key。

数据库 `MediaAsset` 与 COS key 同时绑定 `tenant_id`、适用 `campus_id`、用途、可见性、hash 和状态。跨租户复制必须视为新对象并重新获得批准，不能仅复用 key。

## 4. 上传守卫

- 授权前校验当前 Membership、角色、业务对象与租户/校区范围。
- 允许列表控制 MIME/扩展、用途和大小；服务端依据内容检测，不信任客户端 MIME。
- 只接受逐路由批准的图片和文档类型；拒绝可执行文件、含可执行内容的压缩包、未知格式和未经独立审查/净化的 SVG。服务端同时核对文件内容签名、实际字节数、用途和 SHA-256。
- 图片和文档上限分别为 10 MiB、25 MiB；上传授权有效 10 分钟。超限、扩展名与内容不符、hash 不一致或扫描未完成时，保持不可引用并提供安全失败状态，不接受客户端重试更换为未批准用途。
- 文件名去路径、控制字符和个人信息；存储 key 不使用真实姓名或手机号。
- 上传授权短时、单对象、单动作、最小权限，可撤销；不得写入文档或日志。
- 个人或未成年人素材需要明确同意与用途；本批次一律不使用真人照片/文件。
- 上传完成后验证大小与 SHA-256，必要时经过隔离/扫描状态再可引用。

## 5. 读取、公开与分享

- 内部文件每次读取由后端校验可信身份、租户、校区、角色、当前关系/能力、对象引用及版本，再签发 5 分钟下载链接；链接只对单一对象和读取动作有效，不含列举或写入能力。
- 公开文件只能由当前已发布公开投影引用；草稿、下架、同意撤回或归档后立即停止新签发并清除应用侧缓存。已发签名链接若供应商不能即时撤销，仍最多可用至其 5 分钟期限届满。
- 分享链接仅用于明确授权的对象、动作和接收范围；不使用永久公共桶替代授权。撤销应用授权后停止签发新链接并清除应用侧缓存；已发出的签名链接若供应商不支持即时撤销，最多在其 5 分钟有效期届满时失效。高风险撤回/删除还需按批准流程删除或轮换对象，不能把“撤销申请”写成已让旧链接即时失效。
- 日志、审计、页面缓存和 AI 输入不得保存完整签名 URL。
- 平台管理员默认不能借 COS 控制面读取学生文件；支持例外需单独批准、限时、最小权限和审计。

## 6. 引用、替换与删除

内容版本引用稳定 `MediaAsset.id` 及其不可变版本。每次取用必须重新检查当前对象状态、用途、租户/校区、业务引用和发布版本；替换创建新版本或新对象，不静默覆盖已发布历史。撤回发布、撤销同意、关系失效、归档或删除后停止授权新读取，并使应用侧缓存/引用失效；已发签名链接的实际剩余有效期按第 5 节处理。归档前检查所有引用并提示；强制删除需要业务目的结束、授权、引用解除和审计。家长/机构提出 AI 或个人数据删除时，文件对象、数据库引用、缓存、导出副本和派生结果协同处置，返回可核对状态，不声称本批次已执行真实删除。

## 7. 环境与密钥

local/dev/test/staging/prod 使用独立账号、桶或强隔离命名空间及独立密钥；禁止生产密钥进入非生产环境、客户端、Git、文档或日志。密钥只由未来批准的服务端秘密管理提供，不能存入数据库业务字段。

## 8. 审计与降级

上传意图、内容校验、引用/替换、公开/下架、下载授权、归档、删除和受控支持访问记录最小审计。COS 不可用或校验失败时显示可重试/返回，不把文件设为成功、不切换到未批准外部存储、不公开内部文件。

具体桶结构、区域、加密密钥、版本控制、生命周期天数、CDN、防病毒方案、图片处理和成本阈值留待后续批准，不在本批次假设。

## 9. 数据导出与短时下载

导出不是“任意表打包”。每项申请须由服务端确认业务目的、申请角色、目标对象/记录范围、时间范围、允许字段、接收人、当前授权版本和输出格式；客户端不能提交 `tenant_id`、扩权角色、原始查询或任意字段列表。普通业务导出中，家长仅能导出本人有效关系下的 A2 四字段投影（使用时长、完成情况、知识点摘要、已人工复核的需关注项）；教师仅限当前授权班级和教学用途；机构/校区管理角色仅限其管理范围内已批准的汇总。访客和默认工作人员没有学生数据导出能力。

个人信息查阅/复制是与普通业务导出分开的用途。仅对已核验、已批准的 `PrivacyRequest` 使用 `DATA_SUBJECT_RIGHTS_COPY`；服务端解析申请主体本人或经核验监护关系可代表的范围与批准数据类别，不能由客户端指定表、字段、校区或记录。该用途不受 A2 日常业务摘要四字段限制，但仍须遵守本项目已确定的家长可见边界，不得包括其他学生信息、模型内部日志或教师待复核材料；类别边界和依法需要的例外须经专业审阅。未完成身份/监护核验、请求未批准或范围无法解析时拒绝生成，不通过放宽角色投影补救。

生成文件时和下载时均重新验证身份、Membership、`tenant_id`、适用 `campus_id`、对象/GuardianRelationship、记录状态和版本。权限变化、关系解除、对象下架、撤销或导出过期后拒绝下载；导出文件置于私有存储，下载使用 5 分钟、单文件只读授权，不得产生永久地址或绕过业务授权的 COS 链接。超过未来批准的行数、时长或体积上限时应明确失败或要求缩小范围，不能静默截断或分批扩大权限；具体上限未批准前不实现真实导出。

建议审计事件为 `file.upload_intent.created`、`file.upload.verified`、`file.reference.changed`、`file.download_intent.issued`、`file.access.revoked`、`file.deleted`、`export.requested`、`export.generated`、`export.download_intent.issued`、`export.revoked`、`export.expired`、`export.failed`，以及区分普通业务导出的 `privacy.copy.requested`、`privacy.copy.generated`、`privacy.copy.download_intent.issued`。最少记录事件 ID、请求关联 ID、可信主体/Membership、租户/校区、用途、对象或导出任务/权利请求 ID、字段/范围策略版本、结果与时间；不记录文件正文、完整文件名中的个人信息、签名 URL、密钥或模型/学生原始内容。实际审计字段和保存期限需与 R3、R6、R7 及正式数据规则一并审阅，本节不设法定期限。
