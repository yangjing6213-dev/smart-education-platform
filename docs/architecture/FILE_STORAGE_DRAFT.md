# 文件存储草案

## 1. 边界

未来候选文件服务为腾讯云 COS；本批次不创建桶、账号、策略、上传代码、真实文件或签名链接。原型只使用自制占位图、CSS 图标和简单 SVG。

## 2. 文件生命周期

```text
业务对象请求上传意图
→ 服务端校验身份、tenant/campus范围、用途、类型与大小策略
→ 服务端生成不透明MediaAsset与COS key
→ 签发限定对象/动作/大小/类型的短时上传授权
→ 上传完成回调/确认
→ 服务端检测MIME、大小、SHA-256与安全状态
→ AVAILABLE
→ 被内容版本引用为REFERENCED
→ 解除引用后ARCHIVED
→ 按批准策略删除或保留最小审计
```

任何检测失败、范围冲突或上传未完成都不能进入可引用状态。当前只描述流程，不运行真实上传或恶意文件扫描。

## 3. 对象键与隔离

概念键：`tenants/{tenant_id}/campuses/{campus_id-or-tenant}/assets/{opaque_id}/{version}`。服务端生成全部片段；客户端文件名只作经过净化的显示元数据，不参与授权路径。机构级文件仍位于明确租户前缀；校区文件必须包含 `campus_id` 分段。

数据库 `MediaAsset` 与 COS key 同时绑定 `tenant_id`、适用 `campus_id`、用途、可见性、hash 和状态。跨租户复制必须视为新对象并重新获得批准，不能仅复用 key。

## 4. 上传守卫

- 授权前校验当前 Membership、角色、业务对象与租户/校区范围。
- 允许列表控制 MIME/扩展、用途和大小；服务端依据内容检测，不信任客户端 MIME。
- 文件名去路径、控制字符和个人信息；存储 key 不使用真实姓名或手机号。
- 上传授权短时、单对象、单动作、最小权限，可撤销；不得写入文档或日志。
- 个人或未成年人素材需要明确同意与用途；本批次一律不使用真人照片/文件。
- 上传完成后验证大小与 SHA-256，必要时经过隔离/扫描状态再可引用。

## 5. 读取、公开与分享

- 内部文件每次读取由后端校验租户、校区、角色和对象引用，再签发短时下载链接。
- 公开文件只能由已发布公开投影引用；草稿、已下架、同意撤回或文件归档后链接失效。
- 分享链接短时有效，限定文件、动作和可选处置；不使用永久公共桶替代授权。
- 日志、审计、页面缓存和 AI 输入不得保存完整签名 URL。
- 平台管理员默认不能借 COS 控制面读取学生文件；支持例外需单独批准、限时、最小权限和审计。

## 6. 引用、替换与删除

内容版本引用稳定 `MediaAsset.id`。替换创建新版本或新对象，不静默覆盖已发布历史。归档前检查引用并提示；强制删除需要业务目的结束、授权、引用解除和审计。家长/机构提出 AI 或个人数据删除时，文件删除与数据库引用、缓存和派生结果协同处理，并返回最小状态，不声称本批次已执行真实删除。

## 7. 环境与密钥

local/dev/test/staging/prod 使用独立账号、桶或强隔离命名空间及独立密钥；禁止生产密钥进入非生产环境、客户端、Git、文档或日志。密钥只由未来批准的服务端秘密管理提供，不能存入数据库业务字段。

## 8. 审计与降级

上传意图、完成、引用、公开、下载授权、归档、删除和支持访问记录最小审计。COS 不可用或校验失败时显示可重试/返回，不把文件设为成功、不切换到未批准外部存储、不公开内部文件。

具体桶结构、区域、加密密钥、版本控制、生命周期天数、CDN、防病毒方案、图片处理和成本阈值留待后续批准，不在本批次假设。
