# 模块边界草案

## 1. 原则

本草案只为未来 NestJS 模块化单体划分责任，不创建模块代码。每个模块拥有自己的业务规则和数据访问入口；其他模块通过应用服务或明确事件协作，不直接绕过授权读取其表。跨模块调用继续携带服务端解析的可信范围。

## 2. 模块目录

| 模块 | 负责 | 对外能力 | 不负责 |
|---|---|---|---|
| Tenant & Campus | 租户生命周期、校区目录、状态 | 可信租户/校区上下文 | 学生正文、平台计费实现 |
| Identity | User 与微信/手机号/网页登录身份绑定 | 身份解析、会话主体 | 角色授权、业务对象 |
| Membership & Authorization | Membership、角色、权限、数据范围 | 策略判定、角色切换、默认拒绝 | 端侧隐藏、跨租户浏览 |
| Public Content | 机构、公开教师、一日流程、活动、餐食公开投影 | 已发布公共读取 | 草稿、内部教师档案 |
| Internal Knowledge | 新人指南、教学资源、搜索范围、伙伴云链接目录 | 授权员工读取 | 外部 API、学生业务 |
| Content Operations | 草稿、预览、发布/下架、排序、版本冲突 | 管理写入与发布事件 | 绕过审计直接公开 |
| File | 媒体元数据、上传意图、引用、归档/删除 | 短时上传/下载授权 | 公开永久桶、客户端自定路径 |
| Guardian & Care | 学生档案、关系、绑定、考勤、请假、接送、异常 | 关系/班级内流程 | AI 推理、支付 |
| Work & Report | 教师任务、班级汇总、教师工作日报 | 任务与日报状态机 | 自动绩效/纪律结论 |
| AI Learning | 同意、监督设置、会话、提示、巩固、教师摘要、删除请求 | 受控 AI 编排边界 | 开放聊天、独立学生账号 |
| Audit & Security | 安全事件、业务动作审计、访问支持证据 | 追加审计、受限查询 | 修改业务事实、保存敏感正文 |
| External Adapters | 微信、COS、未来 AI Provider 等适配器 | 统一出站接口、超时/降级 | 业务授权决策 |
| Platform Operations | 租户目录和平台运行元数据 | 平台级管理边界 | 默认读取租户业务正文 |

## 3. 允许依赖

```text
端/API入口
→ Identity
→ Membership & Authorization
→ 目标业务模块
→ Audit & Security

业务模块 → File（只传受权对象引用）
业务模块 → External Adapters（只经应用服务）
AI Learning → Guardian & Care（只校验关系/班级与同意）
Work & Report → Guardian & Care（只取授权汇总）
Public Content ← Content Operations（只接收已发布投影事件）
```

Tenant & Campus 只提供可信范围，不成为所有业务模块互相耦合的共享数据层。共享技术库只能承载无业务语义的日志、时间、ID 和错误契约。

## 4. 禁止依赖与越界

- 客户端不得直接访问数据库、COS、Redis、AI Provider 或外部 API。
- 业务模块不得从请求体读取并信任 `tenant_id`；不得用前端隐藏代替服务端授权。
- 模块不得直接读取其他模块表来绕过对象范围和审计。
- Public Content 不得读取内部教师档案、学生记录、草稿或已下架正文。
- Platform Operations 不得成为跨租户业务查询后门。
- AI Learning 不得把摘要正文发送给家长、管理角色或平台管理员。
- Audit 不得记录密钥、令牌、签名 URL 或未成年人正文。

## 5. 事务和事件边界

同一业务状态机的强一致写入与审计引用应在一个应用事务边界内设计。跨模块派生结果（如发布投影、日报汇总、AI 教师摘要）使用可重试的内部事件概念，并携带服务端租户/校区范围、对象 ID、事件 ID 和版本。任何重试必须幂等；任务消费者重新验证范围，不能只信任载荷。

当前不选消息中间件，也不创建事件代码。若 PostgreSQL 事务内 outbox 足够，优先于新增基础设施；只有验证需求后才考虑 Redis 队列或其他组件。

## 6. 阶段边界

- V0.1：只定义公开内容、内部知识、轻量内容运营所需模块边界。
- B级关键流程：只定义 Guardian & Care、Work & Report、AI Learning 的概念状态与接口边界。
- C级预留：财务、绩效、招生、证照、物资、多校区经营、SaaS 套餐、支付、AI 阅读计划和平台运营不进入业务实现。
