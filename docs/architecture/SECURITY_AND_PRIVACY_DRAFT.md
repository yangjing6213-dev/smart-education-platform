# 安全与隐私草案

## 1. 目标与边界

目标是在未来实现中默认拒绝越权、最小处理未成年人数据、保留可审计人工责任。本批次只交付设计与模拟原型，不处理真实学生/家长/教师数据，不接真实认证、微信、支付、伙伴云 API、正式 AI、生产数据库或生产密钥。

## 2. 主要信任边界

| 边界 | 主要风险 | 必要控制 |
|---|---|---|
| 客户端→统一API | 伪造租户/角色、篡改状态、输入敏感信息 | 服务端身份与范围注入、允许列表校验、默认拒绝、限流 |
| API→数据库/缓存/任务 | 跨租户查询、缓存污染、任务重放 | 范围化仓储、复合约束、租户键、消费者复核、幂等 |
| API→COS | 路径穿越、永久公开、跨租户下载 | 服务端生成key、短时授权、类型/hash校验、引用守卫 |
| API→外部适配器 | 密钥泄露、供应商故障、数据外传 | 环境隔离、最小载荷、秘密管理、超时/降级、审计 |
| AI输入/输出 | 答案泄露、隐私、伤害、自动标签 | 同意/监督、脱敏、安全网关、分层提示、人工复核 |
| 平台运营→租户 | 支持权限变成跨租户后门 | 默认无正文、单独批准、限时最小权限、完整审计 |

## 3. 数据分类与处理

- L0公开：仅明确发布的机构内容与批准教师公开资料。
- L1内部：指南、资源、配置、普通审计元数据。
- L2个人：User、Membership、员工范围与家长关系元数据。
- L3高敏：未成年人、健康/异常、考勤、接送、学习尝试、AI 会话/摘要与家庭关系。

收集前必须有明确目的和合法授权；默认少字段、少范围、少时长。公开投影与内部源分离。不得从生产表格、聊天截图或公开网页复制个人数据；模拟数据必须明显虚构且标注“模拟数据”，也不得组合字段影射真人。

## 4. 身份、权限与租户

认证只证明 User，授权由当前 Membership、单一角色、`tenant_id`、适用 `campus_id`、班级/关系和对象状态联合决定。客户端租户 ID 不可信；查询、写入、唯一约束、缓存、任务、文件、日志、审计、AI 会话和成本全部隔离。跨租户/校区访问、失效关系或超范围对象统一拒绝并记录最小安全审计。

平台管理员默认无学生具体内容。支持例外必须单独批准、限定租户/对象/字段/时间、只读优先并全程审计；到期撤销。

## 5. 未成年人保护

未成年人能力必须同时具备：监护人同意；教师或家长监督；学生不独立注册；最小采集；输入脱敏；输出安全；不确定时拒答/转教师；人工复核；可关闭；可删除；可审计。家长关系解除、同意撤回、机构开关关闭或安全事件触发后停止新会话并撤销相关访问。

AI 学习只做小学作业引导与错题巩固，学生先尝试后依次使用第0—3层提示与巩固层。摘要正文只回授权教师；家长只见监督开关、会话状态和安全提示，管理角色最多见不含正文的审计元数据。

## 6. 输入、输出与内容安全

- 所有文本、文件名和结构化输入按允许列表、长度/格式和用途校验；输出编码，富文本净化。
- 文件 MIME/大小/hash 由服务端验证；短时链接不进普通日志。
- AI 输入先最小化与脱敏，禁止带真实联系方式、证件、地址、照片或不必要健康信息。
- 禁止 AI 答案倾倒、代写、作弊、情感陪伴、虚拟好友、心理诊断、情绪识别、自动能力标签及自动纪律/处罚/绩效结论。
- 任何未经教师或家长确认的敏感结论不得发送；安全不确定时停止、给出一般安全提示并转授权教师。

伙伴云快捷链接按不可信外部输入处理：使用标准解析器规范化，仅批准 `https` 且 host/path 命中 allowlist；拒绝 userinfo、路径逃逸、未批准端口和 `javascript:`、`data:`、`file:` 等 scheme。服务端不抓取目标、不代理、不盲随重定向；确认页显示规范化主机。链接或策略变更留审计，任何 URL 均不得承载账号、Token 或其他凭据。

## 7. 审计、日志与告警

身份/角色切换、发布、权限分配、绑定、接送、异常、日报、文件、AI 会话/关闭/转教师/删除请求和支持例外需审计。审计记录主体、可信范围、对象、动作、前后状态、结果、时间和关联 ID；不记录密钥、令牌、密码、签名 URL 或敏感正文。普通业务角色不能修改审计。未来安全告警需去重、限范围并由人工处理，不自动处罚用户或教师。

## 8. 删除、保留与数据主体控制

删除请求使用独立受审计状态机，与 AI 监督开关正交；受理后明确 `PENDING/COMPLETED/REJECTED` 与最小结果。删除范围应覆盖批准的主记录、文件、缓存和派生结果，同时保留经批准的最小审计事实。精确保留期、法律依据、备份删除和申诉流程需后续由机构与专业意见确认，本批次不虚构。

## 9. 密钥、供应链与环境

生产密钥不进入客户端、Git、文档、镜像或日志。各环境使用独立账号和秘密；缺失秘密时安全失败。不安装未批准依赖，不在本批次生成 lockfile、容器或流水线。未来依赖需固定版本、来源审查、漏洞处理与最小权限构建。

## 10. 降级与事件处理

数据库、COS、微信或 AI 不可用时不伪造成功、不跨租户回退、不展示草稿或旧敏感缓存。AI 降级为安全提示、转教师或关闭。发现疑似越权/泄露时停止相关访问，保留不含正文的证据，通知授权处理者并按批准流程调查、修复和删除；本批次不声明存在正式应急体系。

## 11. 当前非范围与剩余风险

本草案未完成正式威胁建模、合规意见、渗透测试、密码学/认证选型、生产配置、备份容灾或供应商评估。单机构低保真原型不能证明生产安全；后续实现必须以自动化权限测试、跨租户测试、人工安全审查和真实运行约束补充。
