# 安全与隐私草案

## 1. 目标与边界

目标是在未来实现中默认拒绝越权、最小处理未成年人数据、保留可审计人工责任。本批次只交付设计与模拟原型，不处理真实学生/家长/教师数据，不接真实认证、微信、支付、伙伴云 API、正式 AI、生产数据库或生产密钥。

## 2. 主要信任边界

| 边界 | 主要风险 | 必要控制 |
|---|---|---|
| 客户端→统一API | 伪造租户/角色、篡改状态、输入敏感信息 | 服务端身份与范围注入、允许列表校验、默认拒绝、限流 |
| API→数据库/缓存/任务 | 跨租户查询、缓存污染、任务重放 | 范围化仓储、复合约束、租户键、消费者复核、幂等 |
| API→COS | 路径穿越、永久公开、跨租户下载 | 服务端生成key、短时授权、类型/hash校验、引用守卫 |
| API→外部适配器 | 密钥泄露、供应商故障、数据外传 | 环境隔离、最小载荷、秘密管理、超时/降级、审计 |
| AI输入/输出 | 答案泄露、隐私、伤害、自动标签 | 同意/监督、脱敏、安全网关、分层提示、人工复核 |
| 平台运营→租户 | 支持权限变成跨租户后门 | 默认无正文、单独批准、限时最小权限、完整审计 |

## 3. 数据分类与处理

- L0公开：仅明确发布的机构内容与批准教师公开资料。
- L1内部：指南、资源、配置、普通审计元数据。
- L2个人：User、Membership、员工范围与家长关系元数据。
- L3高敏：未成年人、健康/异常、考勤、接送、学习尝试、AI 会话/摘要与家庭关系。

收集前必须有明确目的和合法授权；默认少字段、少范围、少时长。公开投影与内部源分离。不得从生产表格、聊天截图或公开网页复制个人数据；模拟数据必须明显虚构且标注“模拟数据”，也不得组合字段影射真人。

## 4. 身份、权限与租户

认证只证明 User，授权由当前 Membership、单一角色、`tenant_id`、适用 `campus_id`、班级/关系和对象状态联合决定。客户端租户 ID 不可信；查询、写入、唯一约束、缓存、任务、文件、日志、审计、AI 会话和成本全部隔离。跨租户/校区访问、失效关系或超范围对象统一拒绝并记录最小安全审计。

平台管理员默认无学生具体内容。支持例外必须单独批准、限定租户/对象/字段/时间、只读优先并全程审计；到期撤销。

## 5. 未成年人保护

未成年人能力必须同时具备：监护人同意；教师或家长监督；学生不独立注册；最小采集；输入脱敏；输出安全；不确定时拒答/转教师；人工复核；可关闭；可删除；可审计。家长关系解除、同意撤回、机构开关关闭或安全事件触发后停止新会话并撤销相关访问。

AI 学习只做小学作业引导与错题巩固，学生先尝试后依次使用第0—3层提示与巩固层。教师教学摘要正文只回授权教师；家长另有 A2 家长限定投影，只能查看本人有效关系孩子的使用时长、完成情况、知识点摘要和已人工复核的需关注项。家长不得读取模型内部日志、其他学生或教师待复核材料，敏感判断不得自动发送；管理角色最多见不含正文的审计元数据。

## 6. 输入、输出与内容安全

- 所有文本、文件名和结构化输入按允许列表、长度/格式和用途校验；输出编码，富文本净化。
- 文件 MIME/大小/hash 由服务端验证；短时链接不进普通日志。
- AI 输入先最小化与脱敏，禁止带真实联系方式、证件、地址、照片或不必要健康信息。
- 禁止 AI 答案倾倒、代写、作弊、情感陪伴、虚拟好友、心理诊断、情绪识别、自动能力标签及自动纪律/处罚/绩效结论。
- 任何未经教师或家长确认的敏感结论不得发送；安全不确定时停止、给出一般安全提示并转授权教师。

伙伴云快捷链接按不可信外部输入处理：使用标准解析器规范化，仅批准 `https` 且 host/path 命中 allowlist；拒绝 userinfo、路径逃逸、未批准端口和 `javascript:`、`data:`、`file:` 等 scheme。服务端不抓取目标、不代理、不盲随重定向；确认页显示规范化主机。链接或策略变更留审计，任何 URL 均不得承载账号、Token 或其他凭据。

## 7. 审计、日志与告警

身份/角色切换、发布、权限分配、绑定、接送、异常、日报、文件、AI 会话/关闭/转教师/删除请求和支持例外需审计。审计记录主体、可信范围、对象、动作、前后状态、结果、时间和关联 ID；不记录密钥、令牌、密码、签名 URL 或敏感正文。普通业务角色不能修改审计。未来安全告警需去重、限范围并由人工处理，不自动处罚用户或教师。

## 8. 删除、保留与数据主体控制

删除请求使用独立受审计状态机，与 AI 监督开关正交；受理后明确 `PENDING/COMPLETED/REJECTED` 与最小结果。删除范围应覆盖批准的主记录、文件、缓存和派生结果，同时保留经批准的最小审计事实。精确保留期、法律依据、备份删除和申诉流程需后续由机构与专业意见确认，本批次不虚构。

## 9. 密钥、供应链与环境

生产密钥不进入客户端、Git、文档、镜像或日志。各环境使用独立账号和秘密；缺失秘密时安全失败。不安装未批准依赖，不在本批次生成 lockfile、容器或流水线。未来依赖需固定版本、来源审查、漏洞处理与最小权限构建。

## 10. 降级与事件处理

数据库、COS、微信或 AI 不可用时不伪造成功、不跨租户回退、不展示草稿或旧敏感缓存。AI 降级为安全提示、转教师或关闭。发现疑似越权/泄露时停止相关访问，保留不含正文的证据，通知授权处理者并按批准流程调查、修复和删除；本批次不声明存在正式应急体系。

## 11. 当前非范围与剩余风险

本草案未完成正式威胁建模、合规意见、渗透测试、密码学/认证选型、生产配置、备份容灾或供应商评估。单机构低保真原型不能证明生产安全；后续实现必须以自动化权限测试、跨租户测试、人工安全审查和真实运行约束补充。

## 12. R7 全链路权限与失败安全矩阵（离线设计）

本节只明确后续正式实现的安全门槛，不是生产安全结论、渗透测试结果或真实服务验收。每一层都必须重新核对授权；前一层通过不能替代对象级校验。

### 12.1 链路控制与当前证据

| 链路                 | 正式实现必须满足                                                                                                                      | 当前本地证据与限制                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 身份→User→Membership | 身份由选定提供方验证；服务端解析稳定 User 与单一有效 Membership；禁止客户端伪造角色/租户/校区；暂停/撤销后按 R2 拒绝旧会话            | `authPlugin` 拒绝若干伪造身份声明，认证结果由注入函数提供；`LocalSessions` 是本机固定合成身份与内存会话，不是正式身份提供方 |
| API→权限→业务对象    | 路由声明认证/范围要求；领域层每次验证动作、租户、校区、班级/关系、对象状态与版本；无权限统一失败，不能只靠隐藏按钮                    | 有 `authRequired`/`scopeRequired` 插件、路由注册护栏及部分本地对象越权测试；尚无覆盖全部业务端点的生产路由/角色证据         |
| 数据库→并发→审计     | 查询、写入、唯一约束和审计均带可信租户范围；业务变更、版本递增与必要审计原子提交；并发冲突不覆盖新状态                                | 当前 `LocalRepository` 使用进程内 `Map`；R3 仅定义未来事务/冲突契约，无 PostgreSQL、跨设备或持久化证明                      |
| 缓存→后台任务        | 键必须包含租户及所需校区、对象和授权版本；消费者执行时重新验证当前成员/关系/对象权限；失效后清缓存并拒绝迟到任务                      | 本轮未定位到已接入的正式缓存/队列消费者；不能据此宣称此链路已覆盖，需在真实组件选型后补测                                   |
| 文件→临时读取→导出   | 文件意图与对象引用绑定用途、租户/校区/对象/版本；链接短时且可撤销；导出重新应用范围投影；凭据、令牌和敏感正文不进日志                 | 有本地文件意图、类型/大小/摘要校验及范围/过期逻辑；未接入 COS，未验证真实下载链接、文件扫描或导出运行链                     |
| AI→家长/教师投影     | 教师正文只给授权班级教师；家长只给本人有效关系的四类 A2 投影，需关注项先人工复核；机构/平台角色不读取正文；不确定或撤权时丢弃迟到结果 | 当前仅固定题和本机合成摘要/监督服务；无正式 AI Provider。D106C 有限模拟器交互已复核，覆盖关系/摘要查看与切换、联系意向及时长/上限/提示选项；不代表完整 A2 闭环或真实 AI 服务 |
| 消息→回执            | 业务发布、渠道发送、送达、已读、知悉是不同状态；渠道失败不伪造成功；接收人/学生关系/版本改变后不得复用旧回执                          | 本地通知只模拟发布与家长回执，没有外部发送/送达；不能当作实际消息能力                                                       |
| 审计→告警→处置       | 敏感变更记录执行者、可信范围、对象、前后状态、结果和关联 ID；不记录密钥/令牌/敏感正文；读取审计本身受限，告警交由人工                 | 存在本地 `InMemoryAuditStore`、Admin 审计过滤与合成记录；无持久审计、正式告警或事件响应演练                                 |

### 12.2 必须持续成立的拒绝规则

- 任一请求缺少可信身份、有效 Membership、必要能力或对象关系时默认拒绝；客户端给出的 `tenant_id`、角色、校区、学生 ID 不可扩大权限。对敏感对象，“不存在”和“无权访问”使用不泄露对象信息的对外结果。
- 关系解除、成员暂停/撤销、校区/班级范围变化、同意撤回或策略版本改变后，旧 `RequestScope`、缓存、文件链接、异步结果和后台任务均不得继续读取或写入受保护数据。与 R2 一致，真实跨端失效时间及传播机制必须在部署设计中给出并验证。
- 与 R3 一致，状态变更与版本条件写入必须原子；冲突不得覆盖，必要审计不能在业务失败时被单独伪报成功。外部依赖失败时不得跨租户回退、展示旧敏感缓存或伪造发送/存储成功。
- 家长投影必须采用独立字段允许列表，只包含已批准绑定孩子的使用时长、完成情况、知识点摘要和经人工复核的需关注项；不返回教师待复核材料、原始会话/模型内部日志、其他孩子或可还原这些信息的引用。机构/平台只能按批准范围查看汇总或无正文审计元数据。读取以本人当前有效关系和字段审核状态为准；监护同意及家长/机构监督开关控制新会话与续写，不应被当作隐藏已授权历史投影的唯一条件。关系撤销、隐私删除或其他明确撤权规则仍须立即生效。

### 12.3 未来真实实现的负向验收

| 场景                                                    | 必须观察到的结果                                                                            |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 伪造身份、角色、租户或校区声明                          | 认证失败或范围拒绝；无业务数据返回；保留最小安全事件                                        |
| 跨租户、跨校区、跨班级/GuardianRelationship 读取与写入  | 拒绝或安全空结果；不得靠猜测对象 ID 发现其存在                                              |
| 旧版本、成员冻结、解绑或撤回同意后的会话/请求/缓存/任务 | 拒绝旧上下文；丢弃迟到结果；不恢复旧儿童数据                                                |
| 并发写、同一幂等键异载荷、业务提交中途失败              | 一致性遵守 R3；不部分写入、不覆盖、不漏必要审计                                             |
| 过期、撤销、错对象或错校区的文件读取/导出               | 拒绝访问；链接和导出字段按当前范围重新校验                                                  |
| 家长摘要字段越界或需关注项尚未人工复核                  | 拒绝多余字段；无教师内部正文、模型内部记录或其他学生信息                                    |
| 关闭家长/机构监督开关但关系仍有效                       | 阻止新会话/续写；不因监督开关单独隐藏已授权的 A2 历史投影；关系撤销或隐私删除后立即停止读取 |
| 消息/AI/COS/数据库不可用或权限传播失败                  | 显示失败/安全状态，不伪造成功、不展示旧敏感数据、不降级扩大权限                             |
| 审计查询、平台支持或管理角色查看正文                    | 只返回获准范围和最少元数据；无令牌、密钥、签名链接或敏感正文                                |

### 12.4 未完成的正式安全证据

本地合成测试只证明对应测试覆盖的代码路径。正式接入仍需逐端点能力矩阵、真实数据库隔离/并发验证、缓存与任务消费者复核、文件/导出链接测试、供应商故障与安全降级演练、持久审计和人工告警流程、威胁建模及独立安全审查；本任务未执行渗透测试或生产环境验证。
