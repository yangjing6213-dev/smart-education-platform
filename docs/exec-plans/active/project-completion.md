# 剩余实施计划

更新：2026-11-13。此公开摘要与根 `PLANS.md` 共用相同事实，不另建治理版本。目标是优先交付已开发并验证的功能，再持续补齐其余功能。

1. **完成发布版本对齐。** 复用通过的 15 项矩阵、固定 Mini 实点和网站 Linux 私有试运行。核对线上 API 与当前客户端的路由、数据库结构和运行依赖；当前模板 MATCH，新 231 文件业务运行包已准备，但未部署。发现差异时只验证受影响范围，保留完整回退组合。
2. **顺序执行发布。** 在本地门禁和目标校验通过后，提交并推送明确源码清单；部署网站与兼容后端并检查公网页面、静态资源、登录及角色边界；向既有微信 AppID 上传固定产物，提交平台审核，审核通过后发布。分别记录提交、包哈希、公网结果及微信平台结果，失败回退相应版本，不把临时试运行写成上线。
3. **交付后继续开发。** 收集实际使用反馈，优先修复阻断流程和权限隔离问题；未实现的完整业务能力按原产品方案分批落实，每批复用已有验证证据。上线前后的新增需求不能追溯改变已验证包的身份。

当前已验证范围包括家长提交关系、员工审核、成长记录草稿至发布及家长查看、防重复提交。已完成的本地验证不代表所有原方案能力完成，也不代表真实机构数据接入已获授权。

公开源码不包含三张私有照片。构建前按 [私有照片准备](../../operations/private-photos.md) 注入固定素材；已验证线上候选产物已经包含经授权的照片。未准备照片的干净 checkout 不是可独立构建的完整输入。
