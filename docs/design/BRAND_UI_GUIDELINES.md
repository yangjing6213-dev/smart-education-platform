# 同芯学园品牌与跨端 UI 规范

## 品牌定位

同芯学园表达“温暖照护、清楚沟通、共同成长”。界面优先建立可信感，再提供儿童友好的轻量辅助色；安全、接送、健康、异常和费用场景保持克制。

## 品牌信号

- 主识别：批准的同芯学园 Logo，保持原始比例和清晰安全区。
- 主色角色：深绿用于标题、关键操作和导航选中；明亮品牌绿用于标记和轻背景，不作为小号白字按钮底色。
- 温度信号：少量黄、珊瑚、天空蓝和薄荷绿用于分类或状态，不堆叠在同一屏。
- 内容信号：每个主要区域都回答“现在是什么、谁负责、下一步是什么”。

## 端侧语言

| 端 | 视觉重心 | 交互密度 |
|---|---|---|
| 访客小程序 | 品牌、教师、活动、餐食、联系 | 轻量单列，快速进入详情 |
| 访客/家长网页 | 长内容、历史、状态、监督设置 | 章节化，可返回和比较 |
| 家长小程序 | 孩子状态、安全、通知、接送 | 现场动作优先 |
| 教师小程序 | 任务、班级、异常、日报 | 快捷操作优先 |
| 教师用户网页 | 完整待办、历史、日报编辑 | 多区块阅读和编辑 |
| 机构管理网页 | 配置、权限、表格、审计 | 高密度但清晰，禁止装饰抢焦点 |

## 页面原则

1. 一个页面一个主要动作；次要动作降级为文本链接或菜单。
2. 卡片不嵌套卡片；页面分区使用全宽布局和清晰标题。
3. 任何状态同时显示文字、图标或结构变化，不能只靠颜色。
4. 重要动作有明确成功、失败、加载、空状态和返回路径。
5. 所有模拟数据用“模拟数据”标记，不使用可回溯真人信息。

## 禁止

不使用排行榜、积分、虚拟货币、游戏等级、机器人角色、拟人化 AI、外部图片、外部字体、渐变背景、装饰性光球或参考图完整构图。
