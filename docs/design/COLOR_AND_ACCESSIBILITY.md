# 色彩与可访问性

## 色彩令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| brand-lime | #9FD246 | Logo 呼应、轻量强调、装饰线 |
| brand-deep | #356B32 | 主按钮、选中态、标题强调 |
| brand-soft | #EFF8DF | 轻背景、提示区 |
| brand-yellow | #FFD84D | 非危险提醒、分类标记 |
| sky | #7EC8F5 | 信息分类，不单独传达成功 |
| coral | #FF9A86 | 温和提醒、活动分类 |
| mint | #8FD9B6 | 完成或生活内容分类 |
| page | #F6F8F3 | 页面背景 |
| surface | #FFFFFF | 卡片和控件背景 |
| ink | #1F2A1B | 主要文字 |
| muted | #526257 | 次要文字 |
| border | #D9E4D4 | 边框和分隔线 |
| success | #247A42 | 成功文字和图标 |
| info | #1769AA | 信息文字和图标 |
| warning | #8A5300 | 警告文字和图标 |
| danger | #B42318 | 错误文字和图标 |

## 使用比例

页面默认约 70% 中性浅色、20% 品牌绿色体系、10% 辅助色和状态色。单屏原则上只用一个主色和两个辅助色；安全、接送、健康、异常、费用不使用儿童装饰。

## 对比度与状态

- 正文使用 ink 或 muted；不得在 brand-lime、yellow、sky、coral 上直接放小号白字。
- 主按钮使用 brand-deep + 白字；危险按钮使用 danger + 白字；次要按钮使用 surface + ink + border。
- 正文至少 16px，辅助信息至少 13px；图标旁始终有文字或可访问名称。
- 默认、悬停、焦点、禁用、成功、错误和加载均有文字或结构差异。
- 焦点环使用 2px brand-deep 外环并保留 2px 间隔；不得用颜色变化作为唯一焦点提示。

## 可访问性验收

- 键盘可到达所有控件，Tab 顺序跟随视觉阅读顺序。
- 弹窗和抽屉有标题、语义角色、Escape 关闭和焦点回收。
- 触控目标最小 44×44 CSS px；表单控件有可见标签和错误关联。
- 支持 prefers-reduced-motion；不闪烁、不自动播放、不以动画传达唯一信息。
- 通过屏幕阅读器的地标、标题层级、按钮名称和状态播报静态检查。
