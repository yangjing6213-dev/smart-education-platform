# 间距、圆角与层级

## 基础尺度

| 令牌 | 值 | 使用 |
|---|---:|---|
| space-1 | 4px | 图标与文字微间距 |
| space-2 | 8px | 控件内间距、紧凑列表 |
| space-3 | 12px | 标签和表格单元格 |
| space-4 | 16px | 默认组件间距 |
| space-5 | 20px | 卡片内边距 |
| space-6 | 24px | 区块间距 |
| space-7 | 32px | 页面分区 |
| space-8 | 40px | 首屏和大区块 |
| space-9 | 48px | 桌面布局留白 |

## 尺寸规则

- 移动页面左右安全边距 16px，桌面内容最大宽度 1200px，管理端主内容最小宽度按表格需求响应。
- 触控按钮高度至少 44px；桌面紧凑表格按钮仍保留可操作面积或提供行级菜单。
- 卡片内边距移动 16px、桌面 20px；信息密度变化不能改变主要操作位置。
- 长文本、表格、筛选器和导航使用稳定列宽、minmax 或 aspect-ratio，避免加载状态跳动。

## 圆角

- 小控件 6px；普通卡片 8px；弹窗和大容器 12px；不使用过度圆润的气泡式容器。
- 表格、输入框和按钮圆角保持同一层级；页面分区不做浮动卡片。
- 不在卡片内再放卡片；重复项可以是独立卡片或表格行。

## 层级

- Level 0：页面背景 page。
- Level 1：surface 区块和普通卡片，1px border，无阴影或极轻阴影。
- Level 2：浮层、抽屉、弹窗，使用明确边框和短阴影，遮罩保持可读性。
- Level 3：仅用于确认或危险操作，不用装饰性阴影强调普通内容。
- 阴影不可替代边界、焦点或状态文字。
