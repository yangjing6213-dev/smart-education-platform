## 2. 可转译原则

1. 把参考图的布局规律转为同芯学园自己的信息架构：管理端用导航和表格，用户网页用长内容与历史，小程序用现场操作和底部导航。
2. 把卡片用作信息分组而非奖励容器；不出现积分、排行榜、徽章、虚拟货币或游戏化等级。
3. 用真实业务状态、时间、负责人和下一步动作表达优先级，不用颜色或装饰单独表达状态。
4. 采用中性浅背景、深色文字和有限品牌色，避免复制参考图的紫色、粉色或蓝色主导气质。
5. 只使用本地原创 SVG 作为插画和图标；Logo 是唯一直接复用的参考输入图像。

## 3. 原型映射

- 访客：品牌首屏、教师与环境、活动、餐食和联系信息，留白多、语气温暖。
- 家长：孩子状态、安全、通知、接送和监督设置，信息优先、操作明确。
- 教师：任务、班级、异常、日报和快捷操作，密度适中、现场按钮显著。
- 机构管理：左侧导航、顶部范围上下文、筛选、表格和审计，不使用大面积儿童插画。
- AI 学习：友好但工具化，不拟人化，不使用朋友、伙伴或情绪角色隐喻。

## 4. 合规检查

- 参考图只作为布局和信息层级研究，不复制人物、机器人、图标、文字、水印、完整页面或原始配色。
- 每个新 SVG 在 B5 扫描外部链接、base64、文字水印和第三方图标路径。
- 设计稿和原型均标注模拟数据，不暗示真实部署或真实服务。
