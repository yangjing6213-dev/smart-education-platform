# 图标与原创插画规则

## 图标

- 使用本项目本地 symbols.svg 中的原创符号；不加载第三方图标库、外部 SVG 或网络资源。
- 图标以 20px/24px 为主，线宽一致，按钮必须配可访问名称；陌生图标提供 tooltip 或可见文字。
- 不能把图标当作唯一状态信息；状态必须同时显示文字或结构。
- 管理端使用功能性线性图标；安全、接送、健康和异常场景避免装饰化图标。

## 原创插画主题

必须提供本地 SVG：welcome-children、teacher-team、meal-care、ai-learning、safety-pickup、empty-state、success-state。

- welcome-children：抽象成长路径和书本形状，不描绘可识别真人。
- teacher-team：几何化协作物件，不复制参考海报人物。
- meal-care：餐盘、叶片和时间卡片，不表达医疗或健康诊断。
- ai-learning：纸张、铅笔和分层提示，不使用机器人、脸或情感角色。
- safety-pickup：门禁卡、时间和确认标记，不绘制真实儿童照片。
- empty-state：容器和轻量线条，说明下一步动作。
- success-state：勾选、路径完成和文字，不使用奖励、积分或烟花。

## 安全与版权

- SVG 只能包含本地 path、shape、text 和必要的 aria 属性；禁止 base64、外链、远程字体、参考图文字、水印和第三方路径。
- 采用抽象几何、有限色块和项目原创构图；不临摹参考图的人物、机器人、动物、完整海报或图标。
- Logo 直接复制前先保持原始像素和比例；不把 Logo 当作插画源素材再加工。
- B5 扫描所有 SVG 的外链、script、foreignObject、data URI 和明显水印词。
