# 设计 QA 清单

## 品牌与原创性

- [ ] Logo 使用批准本地文件，比例、清晰度和安全区正确。
- [ ] 未复制参考图人物、机器人、图标、文案、水印、原配色或完整构图。
- [ ] 新 SVG 均为本地原创，扫描无外链、base64、script、foreignObject、远程字体和水印。
- [ ] 安全、接送、健康、异常和费用界面没有娱乐化装饰。

## 信息与流程

- [ ] 47 个 A 级页面、12 个 B 级流程和 C 级预留可追踪到 PAGE_INVENTORY。
- [ ] 三端职责正确，机构管理只在网页后台。
- [ ] 绑定、教师任务到日报、AI 学习到教师摘要三条闭环有合法终态。
- [ ] AI 先尝试，按第 0/1/2/3 层和 1 至 3 道巩固题推进，可转教师或关闭。
- [ ] 非法跳步、越权、跨租户范围和摘要泄露均被拒绝。

## 可访问性

- [ ] 正文至少 16px，辅助信息至少 13px，触控目标至少 44×44px。
- [ ] 文本对比度达到 WCAG AA；状态同时有文字/图标/结构。
- [ ] 键盘顺序、焦点环、地标、标题、标签和错误关联完整。
- [ ] 弹窗/抽屉支持 Escape 和焦点回收；支持 prefers-reduced-motion。

## 响应式

- [ ] 320×568 无横向溢出、遮挡或不可达主操作。
- [ ] 390×844 小程序底部导航和现场动作稳定。
- [ ] 768/1024/1440 桌面布局不机械复制小程序。
- [ ] 动态长标题、空状态、错误状态和加载状态不改变固定控件尺寸。

## 证据

- [ ] 页面只发起零外部请求，不使用 localStorage/sessionStorage/IndexedDB/Cookie。
- [ ] 样例全部是明确虚构的模拟数据。
- [ ] 每个 PASS 有命令、浏览器或截图证据；无法证明的项目标记 BLOCKED。
- [ ] 设计文档和原型文件位于合同白名单，未改变 Batch A 冻结文件。
