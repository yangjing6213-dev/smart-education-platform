# 交互与动效规则

## 交互状态

- 每个路由提供默认、加载、空、错误和成功/终态；错误状态提供重试或返回。
- 表单先显示校验错误，再允许提交；提交后显示模拟处理中，终态明确说明后续动作。
- 弹窗、抽屉、标签页和筛选器可操作；Escape 关闭临时层并恢复焦点。
- 非法跳步、越权路由、跨角色摘要、AI 越级和未授权范围操作在动作层被拒绝，并显示原因。

## 三条闭环

1. 绑定：未填写必要字段不可提交；待审核、拒绝重提、通过绑定、解除均有状态。
2. 教师日报：任务必须先进入进行中；完成/原因/班级摘要后才能生成草稿；退回可修订，确认后回到工作台。
3. AI：监督开启后学生先尝试；第 0、1、2、3 层按顺序解锁；巩固题后摘要仅回流授权教师；可转教师或关闭。

## 动效

- 默认使用 120-180ms 的 opacity/transform 过渡，强调状态变化而非装饰。
- 不使用自动轮播、闪烁、弹跳、视差、粒子、滚动锁定或游戏奖励动画。
- prefers-reduced-motion 下移除非必要过渡，保留文字、焦点和结构变化。
- 加载状态使用静态 skeleton 或文字，不使用无限旋转作为唯一反馈。

## 反馈层级

- 就地反馈：表单字段、行状态和步骤状态。
- 区域反馈：卡片或页面内告警，保留问题和修复动作。
- 全局反馈：Toast 仅用于非关键成功；关键安全、接送、权限和 AI 介入必须留在页面。
- 不用颜色、动效或声音单独表达状态。
