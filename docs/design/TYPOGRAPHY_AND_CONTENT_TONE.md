# 字体与内容语气

## 字体

- 中文字体栈：Microsoft YaHei, PingFang SC, Noto Sans CJK SC, sans-serif。
- 不加载外部字体；标题使用字重层级，不使用压缩字距或负字距。
- 正文 16px 起，辅助信息 13px 起；桌面标题 28px 内，移动标题 24px 内。
- 行高：正文 1.6，表格 1.45，按钮 1.2；长内容每行控制在舒适阅读宽度。

## 语气

| 场景 | 语气 | 示例 |
|---|---|---|
| 访客 | 温暖、具体、可信 | “看看今天的托管安排” |
| 家长 | 安心、事实优先 | “接送授权待教师核验” |
| 教师 | 简短、行动导向 | “完成任务后补充日报” |
| 管理 | 中性、可审计 | “保存草稿，不会立即对外发布” |
| AI | 引导式、非拟人 | “先写下你的尝试，再选择提示层级” |

## 文案规则

1. 标题描述对象，按钮描述动作，状态描述事实和下一步。
2. 错误信息说明原因、影响和可执行修复；不责备用户。
3. 统一使用“访客”，不使用“游客”作为产品术语。
4. 不承诺模型能力、学习效果、排名、诊断或自动结论。
5. 所有样例对象和内容明显标注“模拟数据”。
6. 未成年人内容最小化，不写真实姓名、电话、地址、照片、健康或家庭关系。

## AI 文案边界

允许：确认已知条件、提示知识点、拆解步骤、必要时解释过程、生成 1 至 3 道同类巩固题。
禁止：开放聊天、答案倾倒、代写、作弊、情感陪伴、虚拟好友、心理诊断、情绪识别、能力标签和自动纪律/绩效结论。
