# 响应式与跨端规则

## 断点

| 视口 | 用途 | 布局规则 |
|---:|---|---|
| 320×568 | 最小移动检查 | 单列、短标题、底部导航固定、安全区留白 |
| 390×844 | 小程序主检查 | 单列卡片，现场动作靠前，必要时双列短项 |
| 768px | 平板/窄桌面 | 内容分栏收窄，表格可横向滚动 |
| 1024px | 桌面过渡 | 用户网页双栏，管理端保留导航和主内容 |
| 1440×1024 | 桌面主检查 | 管理端左侧导航+顶部上下文+主内容，用户网页长内容布局 |

## 端侧差异

- 小程序：顶部标题和角色化底部导航；列表单列；拍照、签到、接送、任务和日报按钮固定在易触区域。
- 用户网页：允许长内容、历史和多孩子/多记录比较；不复制小程序底部导航。
- 管理网页：左侧导航、顶部租户/校区上下文、筛选区、表格和审计；儿童辅助色只用于分类和状态。
- 同一业务对象可跨端共享名称和状态，但每端的主要动作、密度和返回路径独立设计。

## 稳定性

- 使用 CSS Grid minmax、flex-wrap、aspect-ratio、min-height 和 text-wrap: balance，保证文字不溢出或遮挡。
- 按钮、统计卡、表格列和底部导航设置稳定尺寸；加载/空/错误状态不改变主布局。
- 320px 下长词和中文标题允许换行，不用负字距或视口缩放字体。
- 窄屏管理表格转为可滚动表格或行级详情，不隐藏权限、状态和错误信息。

## 验收视口

每个固定截图视图至少在 390×844、1440×1024 验证；额外用 320×568 检查首屏、导航、表单和 AI 面板无重叠。
