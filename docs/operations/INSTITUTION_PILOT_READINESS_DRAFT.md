每项实际材料必须有一条授权记录，至少包含：

- 不含个人信息的材料编号、类别、用途和目标页面；
- 权利人或授权主体、授权依据及其外部证据编号；
- 允许的受众、展示渠道、裁剪或改写范围；
- 是否包含可识别人物或未成年人；如包含，逐项确认合法来源、监护人授权和公开范围；未完成确认时不得使用；
- 有效期、撤回方式、材料负责人、隐私/内容审核状态；
- 最终状态：`AUTHORIZED_AND_REVIEWED`、`HOLD` 或 `REJECTED`。

AI 生成或虚构素材也需要核对来源、许可条件和使用范围；它们不能替代真实机构对品牌、内容或试点范围的确认。默认使用虚构素材，不使用真实儿童照片或学生资料。

## 4. 最多两轮反馈脚本

真实反馈最多两轮。每轮先确认是否仍在授权范围内；只记录去标识化的问题、选择和汇总结论，不复制个人发言、截图、聊天记录或学生信息。

### 第一轮：方向和内容确认

1. 页面表达和品牌方向是否符合机构定位？需要修改的具体部分是什么？
2. 教师能否找到本次范围内的岗位指南和教学资源？缺少哪些经授权的内容？
3. 公开与内部内容的分界是否清楚？是否存在不应展示的材料？
4. 家长和教师的关键流程是否符合试点单位的实际做法？
5. 机构是否愿意进入限定范围的下一轮验证？如果否，缺少什么前置条件？

### 第二轮：修订结果和继续决定

1. 第一轮列出的高优先级问题是否解决？仍未解决的项目是什么？
2. 教师能否在不重复填写的情况下完成选定的日常操作？
3. 家长是否能理解关系、通知和已发布内容的状态？
4. 当前内容授权、数据范围、人工复核和停止机制是否仍然有效？
5. 机构选择“继续小范围验证 / 需要修改 / 暂停”，由授权岗位给出理由。

第二轮结束后不得自动进入第三轮或自动扩大数据/用户范围；任何扩大需另行确认。

## 5. 完整率与成功判断

在试点范围冻结后，先冻结“本次 V0.1 必需内容项”清单，作为分母。只有同时满足以下条件的内容项才计入分子：已确认授权依据、通过隐私和内容审核、属于冻结范围、仍在有效期内，并已在目标页面验证可用。

```text
V0.1 内容完整率 = 合法授权、审核通过且页面可用的必需内容项数
                 ÷ 冻结范围内的必需内容项总数 × 100%
```

目标为 `≥80%`。分母未冻结、授权证据缺失或范围未确认时，结果必须是 `NOT_CALCULABLE`；虚构数据、演示内容和未审核素材不计入分子。达到 80% 也不能豁免个人信息保护、未成年人授权、内容权利或人工复核门槛。

V0.1 合作验证还需确认：机构认可品牌和页面方向；机构提供真实且获授权的核心内容；教师能找到指南和资源；机构明确愿意继续。仅有口头兴趣、没有指定负责岗位、没有真实授权内容或“没有投诉”均不构成通过。

## 6. 停止条件与当前缺项

遇到以下任一情况即暂停对应事项：没有机构授权确认人；材料权属或用途不清；涉及真实未成年人但没有适用授权；公开与内部范围不清；要求导入真实账号/数据、接入外部服务、发送真实通知、付费或部署；反馈超出两轮；需要专业法律或隐私判断但没有合格审核人。
