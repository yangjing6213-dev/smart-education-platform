# 同芯平台环境与持续运行准备清单草案

> 状态：离线准备与证据盘点。当前不是生产就绪、云端部署、真实备份恢复、服务等级承诺或发布批准。本文不包含凭据、真实云报价或可直接执行的生产命令。

## 1. 目的与结论

本稿汇总原方案 R11 对环境分层、容量与费用估算、日志/告警、发布回滚、数据库/文件恢复和供应链的要求，并对照现有架构基线、R10 运营准备、D43 本机演练和 M63 审计。目的是明确哪些内容已有设计、哪些只有本地合成证据、哪些仍需真实环境和负责人提供事实。

**当前结论：** 本地设计与演练只能支持 `LOCAL_PREPARATION`。项目没有经核验的云环境、真实数据库/对象存储、告警接收器、生产密钥托管或实际恢复证据。R11 整体保持未完成，不能据此部署、上传或对外发布。

## 2. 环境隔离矩阵

环境名称沿用 `ENVIRONMENTS_AND_DEPLOYMENT_BASELINE.md`。每种环境都必须有独立配置和访问边界；生产值不得复制到本地或验证环境。

| 环境         | 目标用途               | 数据与外部访问                     | 当前证据/缺口                    |
| ------------ | ---------------------- | ---------------------------------- | -------------------------------- |
| `local`      | 开发、单元与契约检查   | 仅合成数据；默认禁外网             | 本地流程可运行；不是生产隔离证据 |
| `validation` | 浏览器、安全与集成验证 | 可重置合成数据；只允许受控替身     | 需形成独立环境和配置隔离证据     |
| `pilot`      | 单机构试点             | 仅经批准的范围与数据；访问人白名单 | 尚无真实试点、授权或环境         |
| `production` | 未来受控服务           | 受治理数据和正式运行控制           | 当前未配置、未验证、未授权       |

| 隔离对象      | 必须分别管理                 | 本地可核对项                 | 真实环境门槛                   |
| ------------- | ---------------------------- | ---------------------------- | ------------------------------ |
| 配置与终端    | 不同环境的端点和启动校验     | 仓库中的默认值不得指向生产   | 真实配置审阅与连接负向测试     |
| 数据库/缓存   | 独立实例、凭据、命名空间     | 本地是否使用合成数据         | 跨环境访问拒绝和恢复演练       |
| 文件          | 独立对象存储和前缀           | 本机模拟路径与权限           | 实际权限、扫描、备份及隔离恢复 |
| 密钥/签名材料 | 由受控密钥系统注入；日志脱敏 | 不将密钥放入源码、测试或截图 | 供应商/权限/轮换/审计验证      |
| 日志/审计     | 独立接收端和访问范围         | 不含儿童正文、联系方式、令牌 | 留存依据、访问审计、告警演练   |

## 4. 日志、指标和告警准备

遵循 `OBSERVABILITY_AND_OPERATIONS_BASELINE.md`：日志应使用固定字段与稳定错误码；指标标签有界，不含身份或自由文本；读取敏感摘要也应进入审计。儿童姓名、联系方式、自由文本、原始提示、令牌、签名链接和完整请求正文不得进入普通日志或告警。

| 项目             | 已有设计                                                         | 当前运行证据               | 启用前缺口                           |
| ---------------- | ---------------------------------------------------------------- | -------------------------- | ------------------------------------ |
| 请求日志与错误码 | 时间、服务、环境、请求/关联编号、路由模板、状态、耗时等字段      | 本机检查不等于集中日志     | 真实接收端、脱敏测试和访问审计       |
| 关键指标         | 错误、延迟、鉴权拒绝、范围不匹配、上传扫描、队列/数据库/缓存健康 | 无真实生产负载             | 阈值、基线和容量验证                 |
| 告警             | 持续 5xx、越权拒绝、队列增长、存储/备份失败                      | 无真实告警接收器和值班演练 | 接收人、升级路径、误报处理、演练记录 |
| 事件记录         | 影响范围、开始时间、证据位置、控制措施、责任人、恢复核验         | 仅有设计字段               | 真实职责表、受控记录位置和复盘流程   |

任何告警都不得附带儿童正文、真实凭据或可公开访问的文件链接；告警无人接收、密钥暴露或关键数据未脱敏时不得开放真实流量。

## 5. 发布与回滚门

未来发布至少按“检查源码、依赖锁定和配置 → 在批准环境生成不可变构建物 → 单元/契约/集成/安全检查 → 迁移前备份与兼容性核对 → 健康与就绪检查 → 受限合成冒烟 → 记录构建摘要/迁移号/操作者/回滚目标”的顺序执行。当前禁止实际部署、上传、远程写入和发布。

| 失败类型             | 未来处置原则                               | 当前状态              |
| -------------------- | ------------------------------------------ | --------------------- |
| 仅应用代码失败       | 恢复前一不可变构建物；保持兼容数据结构     | 无生产构建物/回滚演练 |
| 可逆的附加式迁移失败 | 停止并恢复前一构建物；经复核处理未引用结构 | 无真实数据库/迁移     |
| 数据转换错误         | 停止批次，保留检查点，由人工审查修复       | 无真实数据转换        |
| 破坏性变更           | 不在未经审阅的发布中执行，另行审批         | 未执行                |

当前 `scripts/verify-release.mjs` 的历史绑定不能代替本计划的当前发布门；本文件不授权绕过旧验证器或创建新的线上发布方式。

## 6. 数据库与文件备份恢复门

依据 `MIGRATION_AND_ROLLBACK_BASELINE.md`，备份只有在隔离环境恢复并完成数据/租户范围核验后才算可用。正式门槛至少包括：数据库和对象文件清单、加密与权限、备份频率/保留依据、备份失败告警、恢复操作者、隔离目标、恢复前检查、数据一致性核验、恢复后权限/引用核验、记录与复核。

| 必须由负责人批准或验证的项目                | 当前值/证据          |
| ------------------------------------------- | -------------------- |
| RPO（可接受数据缺口）和 RTO（恢复耗时目标） | 〔待负责人批准〕     |
| 数据库、文件、配置与必要审计数据的备份范围  | 〔待确认〕           |
| 加密、访问权限、异地副本和保留/删除依据     | 〔待安全/业务审阅〕  |
| 备份失败告警、值守人及升级责任              | 〔待确认〕           |
| 隔离恢复环境、恢复步骤和租户/文件引用核对   | 〔未验证〕           |
| 最近一次真实恢复日期、结果、复核人          | 〔没有真实恢复证据〕 |

D43 只验证本机临时合成文件流程；M63 只完成文档与只读环境核对。它们不证明数据库或对象存储备份、RPO/RTO、真实回滚或生产恢复。
