目前不得开始真实试点：R8 尚无通过审查的 Provider、处理条款、固定模型版本、预算/停用参数或真实教材许可；也没有真实机构、教师、监护授权或参与安排。当前没有正式 AI，也没有任何试点数据。不得用本地固定题、合成计数或演练结果补填下表。

本方案不允许在本次任务中联系机构或参与者、读取真实儿童数据、联网调用模型、开通付费服务或执行试点。以后满足门槛并经明确批准后，仍须按适用的隐私、儿童保护、安全和人工复核流程执行。

## 4. 指标定义与限制

定义沿用 G44B/D66 的本地指标口径；以下口径在正式试点前仍须核对真实流程，不能直接把合成流程中的结构假设当成真实系统配置。

| 指标               | 记录口径                                                            | 解释限制                                                                                       |
| ------------------ | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 人工复核内容正确率 | 经批准的复核样本中，人工判定符合冻结评分规则的建议数 ÷ 已复核建议数 | 先冻结评分规则、抽样方法和复核角色；只保留总数，不复制儿童输入或建议正文；不等于整体准确性证明 |
| 提示后继续作答率   | 使用过提示且随后再次提交主问题答案的会话数 ÷ 使用过提示的会话数     | 按 G44B/D66 定义；分母为零时无样本                                                             |
| 同类巩固题完成率   | 已回答巩固题数 ÷ 按冻结练习版本可完成的巩固题总数                   | D66 合成演示固定两题；若未来真实流程不同，必须在试点前重新批准分母，不得直接沿用“两题”         |
| 教师实际介入率     | 有已确认教师接手记录的不同会话数 ÷ 会话总数                         | “需要教师跟进”不等于教师已介入；同一会话重复介入按冻结规则计一次                               |
| 作答错误率         | 主问题与巩固题错误作答总数 ÷ 两类作答总数                           | 这是学生作答错误比例，不是 AI 建议正确率；需与上一项人工复核正确率分开报告                     |
| 安全事件与停用     | 按已批准分级记录明确的安全事件数、触发停用数、恢复数和原因类别      | 拒绝/越权尝试不自动等于严重事件；任何严重事件单独升级，不以其他周的均值抵消                    |

除预先批准的定义外，不临时挑选有利指标、变更分母、删除异常周或把相关性解释为因果。未批准样本量、阈值或统计方法时，只报告描述性计数和缺失，不作“有效/提升/减负”结论。
