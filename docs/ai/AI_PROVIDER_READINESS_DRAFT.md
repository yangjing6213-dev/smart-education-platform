# 同芯 AI 助手正式接入前准备清单草案

> 状态：离线准备稿。当前项目不连接正式 AI、RAG、外部供应商或真实儿童数据。本文不是供应商批准、数据处理协议、法律意见、安全认证、模型评测结论或上线授权。

## 1. 用途与边界

本稿把原方案 R8 要求映射到现有 AI 安全、学习流程、产品规格、资料来源治理和评测材料，形成未来正式 AI 接入前的核对清单。目标仍限于受监督的小学作业引导与错题巩固；学生先尝试，再按已定义层级提示并进入巩固。不得扩成开放式聊天、代写、情感陪伴、心理诊断、自动能力标签或自动纪律/绩效判断。

本阶段只整理文档。没有选择 Provider、模型或教材；没有填预算、延迟阈值、通过门槛或供应商条款；不执行联网检查、模型调用、真实评测或真实儿童数据处理。

## 4. 模型替换边界与运行限制

未来若单独批准运行时实现，应由服务端适配器提供稳定的学习请求/安全结果边界；Mini、用户网页和管理网页不得直接持有供应商密钥，也不得自行选租户、学生、Provider 或版本。替换 Provider 时，同一冻结测试集和同一安全规则必须重新评估，不能因切换供应商绕过审批。

每个运行版本至少需要单独登记：环境、Provider、模型名称/不可变版本标识、提示模板版本、安全规则版本、教学资料快照版本、评测集版本、启停状态、批准人和生效范围。运行中不得静默升级模型、提示或教学资料；版本未知、失配或已撤销时拒绝新会话。

| 限制项          | 未来需批准的参数/口径                              | 参数未批准时的安全行为                     |
| --------------- | -------------------------------------------------- | ------------------------------------------ |
| 单会话/租户预算 | 计量单位、预算周期、告警点、硬停止阈值、成本责任人 | 不开真实模型；不以默认无限预算运行         |
| 延迟与超时      | 单次与全会话上限、取消确认、超时用户提示           | 终止请求并转教师/关闭；丢弃迟到输出        |
| 并发与重试      | 每租户/会话并发上限、重试次数/间隔、幂等规则       | 不重试或按已批准上限失败关闭；禁止无界重试 |
| 版本与发布      | 固定版本、变更审批、灰度/回退责任人                | 版本变化即停用，等待复核                   |
| 供应商切换      | 替换审批、差异评测、旧版本数据处理                 | 不自动切换到未批准的备用模型               |

具体数值全部留空，需基于真实合同、容量、成本和安全测试审批；本文没有给出或暗示 SLA。

## 5. 输入净化、图片边界与输出检查

### 输入

- Provider/RAG 之前先校验会话范围、监护同意版本、家长与机构开关、班级/关系权限和资源范围。
- 按字段和长度允许清单处理；识别/删除不必要联系方式、证件/地址、精确学校班级、健康和家庭信息，使用不透明对象引用替代身份。无法安全净化的内容拒绝发送并转教师。
- 脱敏前原文不进入普通日志、评测集、跨租户缓存或供应商请求；最小审计只记录规则/结果类别。
- 当前原型仅有虚构合成题目和文本，不使用图片、不做 OCR、不调用 Provider。图片输入保持关闭；未来如要支持图片，需另行批准来源/授权、内容检测、视觉脱敏、临时存储和删除策略，再独立验证，不能把本稿当作图片安全已实现。

### 输出

未来响应只有同时通过结构、范围、格式、隐私、禁止能力和分层教学校验后才能展示。结果必须匹配当前固定层级、题目/会话版本和巩固题约束；拒绝跨租户内容、原始身份信息、模型内部推理日志、未经人工确认的敏感结论、代写/作弊或陪伴/诊断/标签内容。输出不确定、与安全规则冲突、版本过期、校验器不可用或超时后到达时，丢弃正文并转教师或关闭；不得降级为直接显示原始 Provider 输出。

## 6. 关闭、回退和人工接管

沿用现有安全草案的 fail-closed 边界：Provider、RAG、安全校验、数据库或网络任一必要环节不可用时停止生成；不使用未批准备用模型、不返回缓存答案、不跨租户取内容、不伪造成功。家长撤回、关系失效、家长/机构关闭、教师接管或预算/安全门触发后，停止新请求并取消可取消的在途请求；迟到结果不得写入/展示。

未来真实环境还需要明确由谁执行全局停用、租户/校区范围停用、密钥/供应商故障处置、通知与复核、模型版本回退、残留队列清理及恢复批准。责任人和验证步骤未确认前不得开启运行开关。

## 7. 教学来源与许可审查

每个正式教学资料包至少需记录来源主体、原始材料/授权范围、许可/期限、年级/学科、版本、适用场景、审核人、复核日期、撤回方式和替换/删除结果。只有经过确认可用于该机构、儿童产品和目标处理方式的内容才能入库；未经授权的网页抓取、教材扫描、用户上传作业或其他学生答案不得变成训练/评测材料。

G44 的合成来源审核仅证明本地字段与流程，不证明真实材料拥有使用权。来源争议、许可过期或撤回时停止引用并按文件/资料生命周期处理已派生副本；AI 不能自行判定版权或教学适配。

## 8. 评测与人工发布门

复用 `AI_EVALUATION_DRAFT.md` 已列的 11 维评测和硬门禁，不另造一套效果分数。每次候选变更需冻结 Provider/模型/提示/安全规则/资料/数据集版本，以许可清楚的合成材料运行；保留人工评分分歧和安全失败，不用平均分覆盖硬门禁失败。样本量、各维阈值、严重级别、复测范围、审批角色均待负责人/专业人员批准；未批准时只记录，不声称“通过”。

以下任一项发生时阻止候选开启：跨租户/班级泄露、绕过同意或开关、直接给答案/禁止内容、敏感数据进入供应商/日志/数据集、故障仍生成、迟到结果复活、来源权利不清、Provider 条款未审、预算/时限/关闭策略未设置或关键人工复核缺失。
